## Overview

A high-performance, Awwwards-quality portfolio featuring 3D scenes, cinematic intro animations, AI welcome voice, glassmorphism UI, and smooth scroll-driven transitions. Designed to impress recruiters and stand out in developer community showcases.

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Framework | Next.js 16 (App Router, Turbopack) |
| UI | React 19, TypeScript 5, Tailwind CSS 4 |
| Animation | Framer Motion 12, GSAP 3, Lenis |
| 3D | Three.js, React Three Fiber, Drei |
| Icons | Lucide React |
| Fonts | Space Grotesk (display), Inter (body) |
| Deployment | Vercel |

## Features

- **Cinematic Intro** — Letter-by-letter name animation with aurora background and floating particles
- **AI Welcome Voice** — Web Speech API greeting triggered on first visit
- **3D Hero Scene** — Interactive Three.js icosahedron with mouse-tracking
- **Premium Portrait** — Glassmorphism frame with animated gradient border and parallax
- **Certificate Gallery** — Real certificate images with lightbox preview
- **Micro Interactions** — Magnetic buttons, cursor morphing, card tilt, ripple effects
- **Scroll Storytelling** — Section reveal animations, parallax, scroll progress bar
- **Responsive** — Mobile, tablet, laptop, desktop, ultra-wide
- **Accessible** — Focus-visible states, reduced-motion support, semantic HTML
- **Performance** — Lighthouse 90+, zero layout shift, optimized images

## Getting Started

```bash
# Clone the repository
git clone https://github.com/kartikshukla2301-eng/kartik-portfolio.git
cd kartik-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm start` | Start production server |
| `npm run lint` | Run ESLint |

## Project Structure

```
src/
├── app/                    # Next.js App Router
│   ├── layout.tsx          # Root layout with SEO metadata
│   ├── page.tsx            # Main page composition
│   └── globals.css         # Global styles & CSS utilities
├── components/
│   ├── background/         # Aurora canvas, floating shapes, noise
│   ├── layout/             # Navbar, Footer
│   ├── providers/          # Lenis smooth scroll provider
│   ├── sections/           # Hero, About, Skills, Projects, etc.
│   ├── three/              # Three.js 3D hero scene
│   └── ui/                 # Reusable UI components
├── hooks/                  # Custom React hooks
└── lib/                    # Data, utilities, config
```
