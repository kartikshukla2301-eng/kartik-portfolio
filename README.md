### Detailed Breakdown

* **Core Framework:** [Next.js 16](https://nextjs.org/) utilizing React Server Components (RSC), Turbopack compilation engine, and App Router for zero layout shift and blazing fast page generation.
* **3D Visual Engine:** [Three.js](https://threejs.org/) & [React Three Fiber](https://r3f.docs.pmnd.rs/) rendering an interactive wireframe icosahedron with point lighting, ambient sheen, and mouse-parallax damping.
* **Animation Pipeline:**
  * **Framer Motion 12:** Page transitions, micro-interactions, spring physics, and hover state morphs.
  * **GSAP 3 + ScrollTrigger:** Scrubbed scroll-driven timeline progress with precise spatial pinning.
  * **Lenis:** Smooth inertia scrolling normalized across desktop and mobile browsers.
* **Styling & Theme:** Tailwind CSS v4 configured with dark obsidian surfaces (`#030303`), frosted glass layers (`rgba(255, 255, 255, 0.04)`), and signature neon violet (`#7C5CFF`) and electric cyan (`#22D3EE`) accents.
* **Accessibility:** Automatic detection for `prefers-reduced-motion`, accessible ARIA tags, semantic HTML5 tags, high contrast text ratios, and keyboard navigation.

## 💻 Local Development & Installation

Follow these steps to run the portfolio locally:

### 1. Prerequisites
* **Node.js:** v18.18+ or v20+ recommended
* **Package Manager:** `npm`, `pnpm`, or `yarn`
* **Git:** Version control

### 2. Clone Repository
```bash
git clone https://github.com/kartikshukla2301-eng/kartik-portfolio.git
cd kartik-portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Configure Environment Variables (Optional)
Create a `.env.local` file in the root directory:
```env
# Optional: Increase GitHub API rate limit for contribution data
GITHUB_TOKEN=your_github_personal_access_token
```

### 5. Launch Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 6. Production Build
```bash
npm run build
npm start
```
